# 06 · 摸鱼特性（CLI 版）

> 终端的摸鱼逻辑与 GUI 完全不同：没有全局热键、没有托盘、没有窄窗。
> 核心就一句话：**让这块屏幕"一眼看起来像是在干活"**。
> GUI 版（老板键/托盘/伪装皮肤）已移除，本条为 CLI 替代方案。

---

## 1. 特性清单

| 特性 | 实现方式 |
|---|---|
| **伪装屏** `/bb` | 清屏 → 打印一段"假构建/假测试日志" → 看起来像在跑 CI；再回车 → 恢复对局画面 |
| **终端标题伪装** | 启动即把终端标题设为 `pnpm build`（ANSI OSC），退出时还原；见 §2 |
| **低对比输出** | 不用亮色、不铺大色块；判定只用 `【是】/【否】/【无关】/【一半】` 文字标签 |
| **快速退出** | `Ctrl+C` 立即落盘并退出（真退，不是隐藏）；`/quit` 同理 |
| **挂起恢复** | 落盘即挂起；`soup-cli play --resume <id>` 继续 |

> **没有的东西**：全局老板键（终端拿不到，需要 OS 级钩子，超出范围）、托盘、窄窗、进程改名——
> 这些是 GUI 专属，本项目不做。

---

## 2. 关键实现约束

- **响应速度**：`/bb` 与恢复必须 <100ms（清屏 + 打印几行而已，无 IO）。
- **必须重绘**：从伪装屏恢复时要**重绘当前对局**（汤面 + 最近若干条对话 + 提示行），
  不能只清屏致上下文丢失。
- **伪装内容要"像真的"**：用常见的构建/测试/依赖安装日志（`vite build`、`cargo test`、
  `pnpm install` 之类），**不要**出现"TODO""示例""假装"这种一眼假字样。
- **非 TTY 降级**：输出被管道/文件重定向时不发控制序列（清屏、改标题），
  伪装屏退化为打印一段纯文本日志。判定用 `io::IsTerminal`。
- **标题还原**：退出（含 Ctrl+C）时必须把终端标题改回运行前的值或空，避免留下痕迹。

---

## 3. 伪装屏内容（示例口径）

一段固定模板 + 随机进度行，例如：

```
$ pnpm build
▲ vite v5.4.21 building for production...
✓ 41 modules transformed.
dist/index.html                 0.39 kB
dist/assets/index-D4f2a1.js    86.08 kB │ gzip: 34.12 kB
✓ built in 1.92s
$ cargo test --workspace
   Compiling turtle-soup v0.1.0
    Finished test [unoptimized] target(s) in 2.04s
     Running unittests src/lib.rs
test result: ok. 42 passed; 0 failed
```

- 打印后停在提示符（不换新行等待），玩家回车即恢复。
- 可预置 2–3 套模板随机选，避免每次一样。
