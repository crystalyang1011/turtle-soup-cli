## 术语表

| 术语 | 含义 |
|---|---|
| 汤面（surface） | 公开给玩家的谜面，有悬念但信息不全 |
| 汤底（truth） | 完整真相，仅 Rust 侧可见，每轮随 system prompt 发给 LLM |
| key_facts | 从汤底拆出的 3–6 条**独立可判定**事实，是进度条、提示、胜负的唯一锚点 |
| core fact | key_facts 中标记 `core=true` 的关键事实（因果链的"因"与"果"），构成胜负硬条件 |
| qa_loop | 问答循环：玩家提问 → 主持人判定 → 更新进度 |
| 猜底（guess） | 玩家给出完整推理，一次性评分，最多 3 次 |
| 老板键 | 全局快捷键 `Alt+X`（**GUI 专属，已移除，CLI 不用**） |
