## 1. T1 全屏布局（ratatui + crossterm）

### 1.1 视口

- 进入时切换 **alternate screen** + 启用 raw mode；退出（/quit、Ctrl+C、EOF、结算后回车）必须完整还原
  终端状态（离开 alternate screen、关 raw mode、还原光标）——任何 panic 路径也要还原（panichook）。
- 最小可用尺寸 **80×24**：小于该尺寸按 §6 降级为纯文本模式。

### 1.2 布局（纵向四区 + 对话流）

```
┌─ 海龟汤 ─────────────────────────── ★ 3/5 ─┐   ← 标题栏（1 行）：游戏名 + 星级/难度
│  【汤面】                                   │
│  一个男人走进酒吧，要了一杯水。老板突然      │   ← 汤面区（固定 4 行，整局常驻）
│  拿出一把枪指着他。男人说谢谢就走了。        │
│  为什么？                                   │
├─────────────────────────────────────────────┤
│  > 他在打嗝吗？                             │
│  ✓ 是的，抓到关键了                          │
│  > 现场有别人吗？                           │
│  - 换个方向试试                              │   ← 对话流：消息… → 输入框上边框 → 输入行
│  ! 他的目的可能不是表面那样                   │      （输入行紧随最后一条消息）
│  ─────────────────────────────────────────  │
│  ❯ _                                        │
│                                             │   ← 内容不足时留白
│  水与枪 D2 · 问 3/60 · 进度 1/5 · /help 帮助 │   ← 状态栏（1 行）
└─────────────────────────────────────────────┘
```

- **汤面区**：整局常驻（这是相对阶段一 REPL 最大的信息架构改进——谜面不用翻历史）。
- **对话流**：消息与输入框是**同一条流**，按 `消息… → 输入框上边框 → 输入行` 顺序排列——
  输入行**紧随最后一条消息**（CLI 式「你说一句、AI 答一句」的连续感），提交后该输入行变成一条消息、
  AI 回复接在其后、新的输入行再次紧随。**内容不足可视高度时下方留白**；超出时整体上滚，
  令输入行停在区域底部（最新始终可见）。
- **条目样式（纯单色，前缀区分）**：消息条目**不着色、不用 emoji**，仅靠单宽前缀区分类型：
  `> ` 提问、`✓ ` 是、`✗ ` 否、`~ ` 一半、`- ` 无关、`! ` 提示、`# ` 汤底、系统事件无前缀。
- **输入行**：以一条上边框（`─`）与上方消息分隔；光标定位到输入末尾（CJK 按显示宽度计）；
  LLM 等待期显示 spinner 态（`◐ 思考中…`），键入不丢。
- **状态栏**：题名/难度/问数/进度/帮助提示，常驻可见。

### 1.3 事件循环

- **空闲阻塞、不空转重绘**：无事件时阻塞在 `EventStream`，只有按键才重绘一帧。
  （每帧 `MoveTo/ShowCursor` 会重置终端光标闪烁相位，导致光标异常抖动——故禁止 100ms 空转重绘。）
- **等 LLM 才按节拍重绘**：`run_animated` 把 LLM future 与 100ms 心跳 `select!`，
  期间持续推进 spinner 动画并重绘；LLM 完成即返回结果。传入的 future 不得借用 `view`/`terminal`。
- **命令兼容**：`/guess`、`/hint`、`/answer`、`/switch`、`/hide`、`/list`、`/status`、`/quit`
  全部保留原语义；`/list`、`/status` 等"输出型"命令的**结果渲染进消息流**（系统事件条目），
  不引入面板切换状态机。快捷键映射见 §5，slash 命令不废除。

## 2. 配色（清爽高对比主题）

| 元素 | 颜色 | 说明 |
|---|---|---|
| 背景 | 默认终端色 | 不整块铺底色，跟随用户终端主题 |
| 边框/标题栏 | Cyan 边框 + 默认前景标题 | 面板结构清晰 |
| 汤面 | 默认前景色、加粗 | 常驻谜面，视觉锚点 |
| 对话流（消息/提问/判定/提示/汤底） | **默认前景色，纯单色** | 只靠前缀区分（`> + - ~ . ! #`），不着色、无 emoji |
| 输入行 | 默认前景色 | `❯ ` 前缀 + 编辑内容 + 光标 |
| 状态栏 | DarkGray 文字 | 低存在感 |
| spinner（busy） | Yellow | 仅等待 LLM 时出现 |

仅使用 ANSI 16 色（兼容 Windows Terminal / conhost / 常见 SSH 终端）。对话流刻意保持单色，
避免判定色过于鲜明；需要强调时未来可另设可选「彩色主题」。

## 3. 组件与代码结构

```
src/ui/
├── mod.rs          # 模块入口、主题常量
├── tui.rs          # alternate screen 进出（含 panic 还原钩子）、事件循环、主渲染循环
├── panels.rs       # 标题栏 / 汤面区 / 消息流 / 输入框 / 状态栏 的渲染函数
└── text.rs         # 非 TTY / 窄终端降级输出（与 TUI 共用同一"渲染模型"）
```

- 渲染模型：面板消费的是**不可变视图 DTO**（汤面、消息列表、进度、状态、输入缓冲、busy 态），
  由装配层从 `Session` / `AskHostResult` 等映射而来；`ui/` 不 import `llm`，不触碰 `truth`
  （结算 DTO 显式携带时除外）。
- `bin/soup_cli.rs`：`play` 子命令根据 `IsTerminal`、终端尺寸与 `--no-tui` 标志选择 TUI / 纯文本渲染器装配。

## 4. hub 预埋（T1 末尾，最小接口）

平台需要但不抽象过度——只落三个东西，等第二个游戏（猜词）来校正：

1. `trait Game`：`id() / title() / entry(&mut Terminal)` —— 每个游戏一个实现（海龟汤为首个注册项）；
2. 游戏注册表：`Vec<Box<dyn Game>>`，T2 的 hub 首页直接遍历渲染；
3. `soup-cli play` = 直接进海龟汤；T2 增加 `soup-cli`（无参数）进 hub 选择页。

**禁止**：为"未来游戏"预设数据结构 / prompt 接口 / 打包格式；game pack 是独立立项（阶段三候选）。

## 5. 键位（T1）

| 键 | 行为 |
|---|---|
| 回车 | 提交输入（提问 / slash 命令） |
| `Backspace` | 删除光标前一个字符 |
| `Delete` | 删除光标处字符 |
| `←/→` | 光标左/右移 |
| `Home` / `Ctrl+A` | 光标移到行首 |
| `End` / `Ctrl+E` | 光标移到行尾 |
| `Ctrl+C` | 落盘退出（同 `/quit`，不弹确认） |
| `Esc` | 清空输入缓冲 |
| `↑/↓` | 输入历史（T1.1 可选） |
| `PgUp/PgDn` | 消息流滚动（T1.1 可选） |
| `Ctrl+L` | 清空消息流显示（不动会话数据；T1.1 可选） |

> 输入行为标准单行编辑器：字符（含 CJK）按**字符**增删，光标可停在中间编辑。

## 6. 降级矩阵（必须全绿才算实现正确）

| 环境 | 行为 |
|---|---|
| Windows Terminal（TTY，≥80×24） | 全屏 TUI |
| conhost（TTY，老终端） | 全屏 TUI（16 色安全集） |
| TTY 但 < 80×24 | 纯文本模式（现有 REPL 输出） |
| 管道/重定向（非 TTY） | **纯文本模式**（现有 REPL 输出） |
| `--no-tui` 标志（新增） | 纯文本模式（逃生门） |

纯文本模式 = 现有 REPL 输出原样保留（脚本/冒烟依赖）。

## 7. 验收标准

1. 全部现有单测通过；`ui/` 新增纯函数（消息截断、布局计算、DTO 映射）单测覆盖。
2. §6 降级矩阵五行逐一人工验证。
3. 对局全流程（开局→问答→/hint→/answer→结算）在 TUI 下与纯文本模式行为一致，会话文件互恢复无损
   （TUI 存的档纯文本模式能续）。
4. 非 TTY 下 `cargo run -- ask` 输出与阶段一逐字节兼容（冒烟脚本依赖）。
5. **终端状态还原**：正常退出、Ctrl+C、panic 三条路径离开后终端均可继续正常输入（alternate screen /
   raw mode 全部还原）。
6. `cargo clippy -D warnings` 全绿；依赖仅 ratatui / crossterm（已入白名单）。
